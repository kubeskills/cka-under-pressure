# Retrospective template

Use this after a drill, especially after a failed or hint-assisted one. The point is to
name *what kind* of gap you had, because each kind needs a different fix.

## 1. Classify what happened

Tick every row that applies, and write the specific moment. Be honest; most drills have
two or three.

| Gap type | Looks like | The fix is | What happened to me |
|---|---|---|---|
| ☐ **Conceptual gap** | I didn't understand how the pieces relate (e.g. what links a Service to Pods). | Study the concept, then explain it aloud without notes. | |
| ☐ **Command / syntax gap** | I knew what to do but not the command, flag, or field name. | Short, repeated reps of that one command from memory. | |
| ☐ **Documentation-navigation gap** | I knew the idea but couldn't find the right page or section quickly. | Practice finding the page; bookmark nothing, rehearse the search path. | |
| ☐ **Environment issue** | Wrong context/namespace, image pull, cluster not ready, tooling problem. | Fix the setup; add it to my pre-drill checklist. | |
| ☐ **Task-reading mistake** | I missed a requirement or constraint ("must remain intact", "not restarted"). | Re-read the criteria after my plan and before I act. Underline constraints. | |
| ☐ **Verification gap** | I stopped at "the command worked" without testing behavior. | Define the check *before* solving; test as the client would. | |
